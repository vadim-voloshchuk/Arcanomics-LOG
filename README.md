# Arcanomics LOG

Исследовательская симуляция городской экономики, погоды и перевозок между регионами. Python строит граф и HTML-карту, JavaScript рассчитывает состояние городов в браузере, а отдельный Python-скрипт анализирует сохранённые CSV.

Основное приложение: [`Analitics/1/Arcanomics/`](Analitics/1/Arcanomics/). Точка входа: [`main.py`](Analitics/1/Arcanomics/main.py).

> **Текущее состояние.** Генерация карты и анализ сохранённых CSV — отдельные операции. В исходниках `logistics.js` дублирует `simulation.js`, а вызываемая функция `updateRoadLogistics()` отсутствует: новый прогон останавливается на этапе логистики. Сохранённый HTML представляет более раннюю версию. Подробности и воспроизведение: [известные ограничения](docs/KNOWN_ISSUES.md). Эта редакция документации сохраняет исходный код и данные без изменений.

## Что есть в проекте

- Четыре региона, 17 городов и 23 дороги при генерации с текущими данными по умолчанию.
- Три товара: `Commodity A`, `Commodity B`, `Commodity C`; специализации городов и почасовой баланс запасов.
- Модели цены `market`, `linear`, `inertia` и локальные погодные коэффициенты.
- Управление длительностью, паузой и продолжением; карта, панели городов и регионов, графики.
- Форматы пяти CSV-выгрузок и аналитика уже сохранённого 30-дневного эксперимента.

Наличие интерфейса и форматов выгрузки не означает, что текущие исходники позволяют завершить новый эксперимент; см. ограничение выше.

## Быстрый старт

Нужны Python 3.10+ и браузер. Команды для PowerShell:

```powershell
git clone https://github.com/vadim-voloshchuk/Arcanomics-LOG.git
cd Arcanomics-LOG
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install networkx pyvis pandas numpy
cd Analitics/1/Arcanomics
..\..\..\.venv\Scripts\python.exe main.py
Start-Process .\interactive_simulation_map.html
```

`requirements.txt` пока пуст, поэтому зависимости перечислены явно. Генерация перезаписывает `data/roads.json` и `interactive_simulation_map.html`; для сохранения исторической карты запускайте её в отдельной копии. Подробные инструкции для Windows и Linux/macOS: [запуск и работа с результатами](docs/GETTING_STARTED.md).
