# Запуск и работа с результатами

[На главную](../README.md)

## Требования

- Python 3.10 или новее: исходники используют аннотации вида `list[str] | None`.
- `networkx` и `pyvis` для генерации карты.
- `pandas` и `numpy` для `src/analytics.py`.
- Браузер с JavaScript. В сохранённой странице есть ссылки на CDN, поэтому наличие `lib/` само по себе не гарантирует работу без интернета.

В репозитории нет npm-проекта, серверного API, базы данных, Docker-конфигурации или автоматического установщика зависимостей. `requirements.txt` пуст; установка с `pip install -r requirements.txt` не установит необходимые пакеты. Версии зависимостей в проекте не закреплены.

## Установка

Команды выполняются из корня клонированного репозитория.

### Windows / PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install networkx pyvis pandas numpy
cd Analitics/1/Arcanomics
..\..\..\.venv\Scripts\python.exe main.py
Start-Process .\interactive_simulation_map.html
```

Активация окружения не обязательна: в командах указан путь к его Python.

### Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/python -m pip install networkx pyvis pandas numpy
cd Analitics/1/Arcanomics
../../../.venv/bin/python main.py
```

После генерации откройте `interactive_simulation_map.html` браузером. При необходимости можно раздавать каталог локально:

```bash
../../../.venv/bin/python -m http.server 8000 --bind 127.0.0.1
```

Адрес: [локальная карта](http://127.0.0.1:8000/interactive_simulation_map.html). В PowerShell используйте `..\..\..\.venv\Scripts\python.exe` вместо `../../../.venv/bin/python`.

## Что делает генерация

`main.py` вызывает `create_graph()`, затем `generate_html()`. При этом перезаписываются:

- `data/roads.json` — рассчитанные дороги;
- `interactive_simulation_map.html` — карта с внедрёнными JavaScript и данными.

Pyvis также может подготовить `lib/` относительно рабочего каталога. Поэтому запускать генератор следует из `Analitics/1/Arcanomics`, как в примерах выше. Если нужна сохранённая историческая страница, сделайте отдельную копию каталога перед генерацией.

Успешное завершение Python означает, что HTML создан. Оно не проверяет выполнение JavaScript. В текущей версии нажатие **Start simulation** приводит к отсутствующей `updateRoadLogistics()`; это [существующая ошибка исходников](KNOWN_ISSUES.md#отсутствующая-функция-логистики).

## Управление в сгенерированном интерфейсе

| Элемент | Действие |
| --- | --- |
| `Price model` | Выбор `market`, `linear` или `inertia` |
| `Simulation duration (days)` | Целое число от 1 до 365; некорректное значение заменяется на 30 |
| `Start simulation` | Создаёт `run_id` и запускает почасовые расчёты |
| `Pause` / `Resume` | Останавливает и возобновляет таймер |
| Выбор регионов | Скрывает узлы и дороги на карте; состав расчёта не меняет |

Для независимого эксперимента перезагрузите страницу перед стартом: повторный `Start` сам по себе не сбрасывает всё состояние. Время по умолчанию начинается с первого дня, 06:00. Один игровой час занимает приблизительно 1,5 секунды реального времени; 30 дней — около 18 минут при активной вкладке и исправном полном цикле. Браузер может замедлять таймеры фоновых вкладок.

## Аналитика уже сохранённых данных

Она запускается отдельно и не требует нового прогона в браузере. Из каталога приложения:

```powershell
..\..\..\.venv\Scripts\python.exe src/analytics.py
```

Для Linux/macOS:

```bash
../../../.venv/bin/python src/analytics.py
```

Скрипт читает `data/price_history.csv`, `data/simulation_log.csv` и, при наличии, `data/routes_history.csv`; результат печатает в терминал. Он не создаёт отчётный файл и не меняет CSV.

При завершении полного цикла JavaScript предусмотрена загрузка пяти CSV через браузер. Они попадают в каталог загрузок, а не автоматически в `data/`. Для анализа нового эксперимента сначала сохраните прежние результаты отдельно, затем поместите в `data/` файлы одного прогона с согласованным `run_id`. Браузер может запросить разрешение на несколько загрузок.

Текущую ошибку логистики нужно устранить отдельным изменением кода, прежде чем рассчитывать на полную выгрузку нового прогона. Схемы файлов и ограничения аналитики описаны в [справочнике данных](DATA.md).
