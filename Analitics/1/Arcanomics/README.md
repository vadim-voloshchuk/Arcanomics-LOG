# Arcanomics

Интерактивная карта с симуляцией экономики, погоды и логистики между городами.

Запуск:

```powershell
python main.py
```

Компоненты приложения находятся в `src/`: Python строит граф и HTML-страницу, а JavaScript-модули управляют состоянием, погодой, экономикой, логистикой и циклом симуляции. Статические описания городов, дорог и товаров находятся в `data/`.

Результат генерации — `interactive_simulation_map.html`. Каталоги `results/` и `experiments/` предусмотрены для сохраняемых результатов и экспериментальных материалов.
