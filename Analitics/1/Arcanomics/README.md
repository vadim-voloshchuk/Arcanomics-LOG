# Arcanomics: основное приложение

Этот каталог содержит модульную версию генератора карты и браузерной симуляции экономики, погоды и логистики.

[Главная страница репозитория](../../../README.md) · [Запуск](../../../docs/GETTING_STARTED.md) · [Архитектура](../../../docs/ARCHITECTURE.md) · [Логика](../../../docs/SIMULATION.md) · [Топология](../../../docs/TOPOLOGY.md) · [Данные](../../../docs/DATA.md)

## Точки входа

```powershell
python main.py
python src/analytics.py
```

Первая команда генерирует `interactive_simulation_map.html` и перезаписывает `data/roads.json`. Вторая независимо анализирует сохранённые CSV и печатает сводку в терминал. Используйте Python из окружения с установленными `networkx`, `pyvis`, `pandas`, `numpy`; `requirements.txt` сейчас пуст.

## Каталоги

| Путь | Содержимое |
| --- | --- |
| [`src/`](src/) | Построение графа, генерация HTML, JavaScript-модель и аналитика |
| [`data/`](data/) | Справочники городов и товаров, дороги, погода, исторические CSV |
| [`lib/`](lib/) | Браузерные библиотеки и вспомогательные файлы |

`results/` и `experiments/` в текущем репозитории отсутствуют. CSV загружаются браузером; для аналитики их нужно вручную поместить в `data/`.

## Состояние реализации

Сохранённый HTML относится к ранней версии и отличается от текущего `src/`. В текущих модулях `logistics.js` дублирует `simulation.js`, а `updateRoadLogistics()` не определена; поэтому генерация HTML возможна, но новый полный прогон прерывается на этапе логистики. Существующие погодные CSV также не совпадают по именам с ожидаемыми `region_*.csv`.

Описание причин и воспроизведения: [известные ограничения](../../../docs/KNOWN_ISSUES.md). Исходный код, данные и артефакты сохранены без изменений при оформлении документации.
